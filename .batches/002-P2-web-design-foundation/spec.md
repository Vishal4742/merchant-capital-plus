## Acceptance criteria
- [ ] `apps/web/app/tokens.css` holds every design-system token with the same values (light + dark). Tailwind 4 `@theme` maps colours, radii and fonts to tokens. There are no hex values in components (grep).
- [ ] Instrument Sans (variable), Instrument Serif (italic) and Geist Mono load through `next/font/google`. The network tab shows no request to fonts.googleapis.com or gstatic.com at runtime.
- [ ] `components/DitherScene.tsx` (client, three.js 0.186.1 loaded with a dynamic import after first paint):
  - the Marine Drive scene as GPU points, 4×4 Bayer dither
  - dots gather on load (about 1.8 s)
  - depth layers drift with the cursor; dots part around it; lamps twinkle
  - `prefers-reduced-motion`: static, with no push or parallax
  - rendering pauses off-screen (IntersectionObserver)
  - unmount disposes the renderer, geometry and material
  - no WebGL or no three.js: a still 2D drawing
- [ ] `lib/dither.ts` is pure, and `test/dither.test.mjs` covers seeding, bounds and depth, the lit moon and dark sky, lamps only on the water, and an empty box.
- [ ] `components/Button.tsx` (primary, glass, quiet; pill; spring press; hover glow; `aria-disabled` styles) and `components/HoldButton.tsx`:
  - a 900 ms hold fill; release cancels
  - a keyboard press confirms at once
  - states busy (pulsing dots) → done → idle; a rejected `onConfirm` returns to idle
  - focus is kept while busy
  - used for "Hold to sign again" on the DEP-3 card
- [ ] The rail-proof page `/` is restyled in the system: a scene header with the wordmark, the proof cards as `surface` cards, status words in pills, pill buttons with the focus ring. The batch 001 behaviour is unchanged (its tests still pass).
- [ ] Theme: follows the OS by default. Both themes pass AA on every text pair the page uses.
- [ ] Screenshots at 375 and 1440, in light and dark.
